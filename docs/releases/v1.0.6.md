# Oberiz v1.0.6 — Requested seasons and cached inventory availability

- Accepting a selected season plus future seasons now includes already-aired episodes of the explicitly selected season. Earlier unselected seasons remain excluded.
- Existing episodes stay available: a season with one of six episodes present retains one available and five missing. Existing upgrade and pack policies remain in effect.
- Previously received Cinetta episode identities are linked when series metadata is loaded and before automated acquisition, without requiring unchanged files to be sent again.
- Reusing cached inventory does not scan NAS paths, initiate Cinetta synchronization, or refresh inventory receipt timestamps. Existing file quality records are preserved; legacy identity-only records have unknown quality.
- The automation interval controls release searches, not Cinetta filesystem rescans. This release fixes missing inventory binding; it does not claim to resolve an unconfirmed remote scheduler interruption.
- Regression coverage includes selected/future seasons, partial availability, metadata refresh persistence, manual exclusions, cached-inventory rebinding, and a simulated full-series-to-season-pack acquisition workflow.
- No database migration is required. After updating, allow a search cycle or refresh affected series metadata; requests affected by the previous future-only selection may need to be reapplied.
- Publishing this release does not update or restart installed services automatically.
