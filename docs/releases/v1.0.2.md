# Oberiz v1.0.2

## Simplified storage

- Selectable inventory: Cinetta through the public API or read-only local scanning. The latest received report date is displayed.
- Without recent Cinetta inventory (24 hours), new acquisitions wait. Previous inventory is preserved and local scanning is not activated.
- Removed direct importing, copying, hardlinks, moving, reseeding folders, and Oberiz-managed SMB connections/credentials.
- Download destinations are configured in qBittorrent categories.

## Optional renaming and recovery

- qBittorrent renaming is configurable in Settings and **disabled by default**, even when upgrading an installation with legacy renaming enabled.
- Persistent journal before name changes, verification of each step, and retries after disconnections without repeating confirmed changes.
- Physical destination checks through the qBittorrent API. Unavailable queries or occupied destinations block renaming.
- The `.torrent` archive, hash, destination, and name mappings are stored in SQLite and included in database backups.
- Stopped v1/hybrid recovery with confirmation and recheck; start/resume commands are never sent automatically. Review file selection and qBittorrent preferences before resuming.
- Sharing policies preserve downloaded files. Manual data-deletion requests are also rejected in this version.

## Upgrade and limitations

- Consistent SQLite backup before applying migration 0022 to an existing installation. History is preserved and legacy SMB credentials removed.
- Legacy records and external `.torrent` files are not converted automatically; they require manual recovery. Pure v2 torrent recovery is manual.
- qBittorrent has no atomic rename-without-replacement operation. Do not run other organizers against the same destinations concurrently. Directory queries cannot guarantee detection of hidden entries not exposed by the API.
- Cinetta requires the Oberiz URL/key and inventory sending enabled. Installing/publishing Oberiz does not configure or modify Cinetta or the NAS.
- Docker media mounting becomes optional and read-only for local scanning. Cinetta API inventory does not require mounting the library.

## Verification

Automated backend and migration tests, frontend compilation and regressions in six languages, and all 11 tests for the existing Cinetta JavaScript sender. Real qBittorrent v5.2.3 was tested using an isolated profile and synthetic torrent: renaming, hash-preserving export, stopped recovery, 100% recheck, and occupied-destination protection through Oberiz Rust code.

No NAS access or user torrent changes were made.
