# Oberiz v1.0.1

- Cinetta inventory is additive by default: omissions do not remove availability without explicit confirmation and a valid root.
- Inventory identity, metadata, and limit validation; authentication and concurrency limiting before JSON.
- Protection for multi-episode files and superseded-version suggestions.
- External mode blocks scanning, reseeding, automatic discovery, and file operations; mode changes are serialized with those operations.
- Imports interface adapted to external mode, with regression tests.
- Inventory contract documented in OpenAPI.

Joint synchronization with Cinetta still requires operational testing before production activation. Tests use synthetic files, in-memory SQLite, and loopback HTTP, without a NAS or real torrents.
