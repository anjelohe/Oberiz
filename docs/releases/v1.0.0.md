# Oberiz v1.0.0 — primera versión

- Biblioteca de películas, series, temporadas y episodios; metadatos TMDB/TVDB, calendario e historial.
- Perfiles de calidad e idioma, monitorización, búsqueda automática y RSS, límites de mejora y protección contra duplicados.
- Indexadores Cardigann, importación web de YAML y condiciones de texto `:contains`.
- qBittorrent con filtros por tracker/categoría/etiqueta y rutas remotas.
- Bibliotecas en varios discos, selección múltiple y escaneo configurable que conserva disponibilidad ante desconexiones.
- Seguimiento persistente de próximos episodios y estados de temporadas incompleta/al día/completa.
- Importación hardlink/copia/mover, renombrado, reseed y políticas de compartición.
- Conexiones SMB opcionales de Windows, credenciales cifradas, selector de recursos y restauración al arrancar el servicio. Linux/Docker utiliza montajes del sistema operativo.
- API pública de peticiones, acceso protegido, copias de seguridad y seis idiomas.
- Interfaz adaptable y temas, incluyendo Middle.

Distribuciones: Windows portable/instalador, Linux x86_64 y Docker. Introducir las credenciales del NAS después de instalar: no se importan desde otras aplicaciones ni se cambian permisos automáticamente.

Verificación de código: 87 pruebas unitarias y una de migración, Clippy, formato, compilación frontend, filtros y cobertura de idiomas. La verificación de credenciales desde el servicio y las pruebas reales de descargas requieren configuración y casos operativos específicos.
