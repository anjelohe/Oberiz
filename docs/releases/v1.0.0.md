# Oberiz v1.0.0 — first release

- Movies, series, seasons, and episodes; TMDB/TVDB metadata, calendar, and history.
- Quality/language profiles, monitoring, automatic search and RSS, upgrade limits, and duplicate protection.
- Cardigann indexers, web YAML import, and `:contains` text conditions.
- qBittorrent with tracker/category/tag filters and remote paths.
- Libraries across multiple disks, multiple selection, and configurable scanning that preserves availability during disconnection.
- Persistent upcoming-episode tracking and incomplete/up-to-date/complete season states.
- Hardlink/copy/move import, renaming, reseeding, and sharing policies.
- Optional Windows SMB connections, encrypted credentials, share picker, and service-start restoration. Linux/Docker uses OS mounts.
- Public request API, protected access, backups, and six languages.
- Responsive interface and themes, including Middle.

Distributions: Windows portable/installer, Linux x86_64, and Docker. Enter NAS credentials after installation: they are not imported from other applications and permissions are not changed automatically.

Code verification: 87 unit tests and one migration test, Clippy, formatting, frontend compilation, filters, and language coverage. Service credential verification and real download testing require specific operational configuration and cases.
