# Oberiz v1.0.3

- La versión de la barra lateral se obtiene del paquete frontend, sin números
  escritos a mano. Se muestra v1.0.3 y se actualiza con futuras compilaciones.
- La primera contraseña puede configurarse desde otro dispositivo o un proxy.
  Completar la configuración en una red de confianza antes de exponer Oberiz:
  quien llegue primero a una instancia sin contraseña puede establecerla.
  Se conservan la serialización, validación, hash y contraseña actual para cambios.
- Descargas pide confirmación para eliminar un torrent y permite marcar «Borrar
  también los archivos descargados», desmarcado por defecto, con aviso permanente.
  qBittorrent ejecuta el borrado incluso sin acceso de Oberiz al NAS. Las políticas
  automáticas y el rechazo de releases conservan los archivos.
- En Inventario de biblioteca se puede activar la pausa si falta el informe Cinetta
  o tiene más de 24 horas. Está desactivada por defecto, también al actualizar.
  Sin activarla, las adquisiciones continúan usando el último inventario disponible.
- Versiones, Docker, OpenAPI y documentación actualizados. Publicar no actualiza
  automáticamente las instalaciones existentes.

Las pruebas de borrado utilizan un servidor simulado, no torrents ni datos reales.
