# Oberiz v1.0.3

- The sidebar version is read from the frontend package rather than hardcoded. It displays v1.0.3 and follows future builds.
- The initial password can be configured from another device or through a proxy. Complete setup on a trusted network before exposing Oberiz: the first visitor to a passwordless instance can set it. Serialization, validation, hashing, and current-password verification for changes are preserved.
- Downloads requires confirmation to delete a torrent and offers “Also delete downloaded files,” unchecked by default, with a persistent warning. qBittorrent executes deletion even without Oberiz NAS access. Automatic policies and release rejection preserve files.
- Library inventory includes an optional pause when the Cinetta report is absent or older than 24 hours. It is disabled by default, including upgrades. Without it, acquisitions continue using the latest available inventory.
- Updated versions, Docker, OpenAPI, and documentation. Publishing does not automatically update existing installations.

Deletion tests use a simulated server, not real torrents or data.
